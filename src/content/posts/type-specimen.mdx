This page exists to exercise the article template. It is not published: it is a
proof sheet for the design system, and it renders every block type an article
can contain so regressions surface here before they reach a real post.

## Prose and emphasis

Body text sets in Inter at a measure of 68 characters. It carries **bold**,
_italic_, `inline code`, and [a link](https://example.com) — each of which has
to hold up against the accent without competing with it.

> A blockquote takes a pink rule on its leading edge. Flat, square, no glow.

## Code frames

A titled frame, with one line marked:

```js title="src/lib/example.js" {2}
const client = createClient();
const result = await client.query('select 1');
export default result;
```

A terminal frame:

```bash frame="terminal"
npx wrangler deploy --config workers/mcp/wrangler.jsonc
```
